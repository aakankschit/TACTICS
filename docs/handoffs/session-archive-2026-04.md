- **2026-04-04**: Decomposed GMIC signal/noise dynamics on all 10 three-component ROCS libraries using full benchmark diagnostics (1.27M rows per library, 109 queries × 20 replicates × 195 cycles). Key finding: GMIC noise denominator is inflated 2-12× above expected (uniform observation) levels because ~85-90% of reagents remain at warmup-level variance while directed search concentrates observations on ~10-15%. This is a limitation of GMIC: it underestimates SNR for the exploited subpopulation. Per-query trajectory classification: signal crash magnitude predicts GMIC direction (r=-0.595, mannich). DOWN trajectories = false positive SAR from warmup (92% signal crash, self-correcting). UP trajectories = real SAR (35-47% signal retained). Mannich (Δ=+2.5): 171 UP, 45 DOWN, 111 FLAT → differential GMIC drives advantage. Orru (Δ=-0.5): 268 UP, 26 DOWN → uniformly easy SAR, no differential. Created Heptabase card with proposed observation-weighted GMIC variant and reagent usage fraction diagnostic plot. Recorded as Paper 3 open question; Paper 1 discussion point (TACTICS outperforms legacy even with conservative estimates).
